Antiphon Standard

Software agents can operate. Decisions people can own.

How should software support useful agent work and meaningful human control? The Antiphon Standard investigates the interface between software, agents and people.

Program overview

Useful delegation needs clear control.

Agents need to understand available actions, inspect progress and check results. People need clear ways to guide work and correct mistakes.

The Antiphon Standard studies these needs across different kinds of software. It builds on existing integration approaches where appropriate.

It is a proposed standard under internal development. It is not an adopted industry standard.

What the research asks

Clear interfaces

Can an agent understand what software can do without unnecessary complexity?

Human judgement

Which decisions need a person, and when should the software ask?

Visible progress

Can people understand what changed and what remains unfinished?

Verified outcomes

Does a reported success correspond to the result the person requested?

Correction and recovery

Can work be corrected, resumed or reversed within clearly stated limits?

Efficient interaction

Can the workflow reduce wasted effort without weakening oversight or output quality?

Evidence and limits

Design goals need real validation.

Current work includes interface design and small internal evaluations. These do not establish production reliability or broad user benefit.

Efficiency gains, adoption and advantages over existing approaches remain unproven. Human approval alone does not guarantee a correct or safe outcome.

This page describes research goals and status. The specification, implementation and evaluation details remain unreleased.

The project remains a research effort.
